# Projet DSL

On explore la famille alignement. 

Le périmètre contient les jeux où l'objectif est lié à l'alignement des pions les uns à côté des autres pour gagner sur un plateau défini et discret (il y a des cases bien défini dans lequel tu peux placer les pions). Il ne contient pas tout autre jeu ayant un autre but du jeu. Il ne contient pas tout les jeux non multijoueur.

Utilisation de l'IA : rien du tout
